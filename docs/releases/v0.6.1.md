# Pebble 0.6.1 · Desktop preview

Free local voice input, clearer task commands, optional one-click Skills, and category personalization while keeping the main interface minimal. Includes the 0.6.0 development changes; 0.6.0 was not a public release.

## What's new

- **Local Chinese / English voice:** microphone controls, editable transcript, action preview and confirmation. First use downloads about 250 MB from Hugging Face; recognition then runs locally using the cached model. No speech API key or subscription. Intel Macs use a WASM fallback.
- **Intent across tabs:** `Complete the meeting` moves the matching task to Done, even from To-do. Start / resume moves it to Doing; reopen moves it to To-do. Exact titles take priority, ambiguous matches require a choice, and unmatched state commands never create a new task. Correct intent with the Action selector before applying.
- **Category customization:** 12 preset colors, custom colors and optional emoji appear in category management and open category options. Main headings, task text and closed selectors remain neutral.
- **Optional Skills:** install a local Codex or Claude Code Skill from Settings → AI connections. It reuses Pebble's runtime, so no separate Node installation or MCP configuration is required for this route. Keep Pebble running and enable AI access. Existing MCP configuration and instructions remain available.
- **Start time only:** record a planned start without inventing an end time.

## Choose a download

| Computer | Installer | Alternative |
| --- | --- | --- |
| Windows x64 | `Pebble-0.6.1-windows-x64.exe` | `Pebble-0.6.1-windows-x64.zip` |
| Mac with Apple Silicon (M-series) | `Pebble-0.6.1-macos-arm64.dmg` | `Pebble-0.6.1-macos-arm64.zip` |
| Mac with an Intel processor | `Pebble-0.6.1-macos-x64.dmg` | `Pebble-0.6.1-macos-x64.zip` |

Windows: quit the old app, then run the installer. For ZIP, extract the entire folder before opening `Pebble.exe`.

macOS: quit the old app, open the matching DMG, and drag Pebble to Applications. Check About This Mac → Chip / Processor to choose arm64 or x64.

Export a task backup in Settings before upgrading. Data is stored separately from the app. After moving the app, reinstall its Skill or regenerate its MCP configuration to update paths. The voice model is downloaded separately and is not included in these packages or task backups.

These preview builds are unsigned; Mac builds are not Developer ID signed or notarized. Review the [installation guide](https://github.com/chenwy777/pebble-todo#installation) and [Apple's guidance](https://support.apple.com/en-au/102445) if needed. All six package checksums are in `SHA256SUMS.txt`.

## Verification and limits

33 unit tests and local Windows packaged-app regressions cover task commands, categories, Skill installation, MCP and desktop behavior. Actual English speech recognition was exercised through native CPU and WASM paths; Chinese recognition still needs transcript review. Mac packages are built separately for each architecture; actual Mac microphone, transparency, dragging and menu-bar acceptance remains pending. Claude client UI acceptance is also pending.

Voice commands use bounded local rules, not general AI reasoning. Skills / MCP currently read context, categories and tasks, and add tasks; they do not edit or complete existing tasks. Voice actions inside Pebble can change existing task status. Skills require local command execution on the same computer, rather than an isolated cloud chat.

No cloud sync, reminder notifications, recurring tasks, automatic startup or actual time tracking. Planned times do not create alarms.
