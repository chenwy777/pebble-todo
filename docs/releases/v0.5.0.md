# Pebble 0.5.0 · Desktop preview

A small transparent orb that opens downward into a to-do list. Includes editable categories, English / Chinese interface, planned time ranges and local MCP tools for Codex and Claude.

## Choose a download

| Computer                          | Installer                      | Alternative                    |
| --------------------------------- | ------------------------------ | ------------------------------ |
| Windows x64                       | `Pebble-0.5.0-windows-x64.exe` | `Pebble-0.5.0-windows-x64.zip` |
| Mac with Apple Silicon (M-series) | `Pebble-0.5.0-macos-arm64.dmg` | `Pebble-0.5.0-macos-arm64.zip` |
| Mac with an Intel processor       | `Pebble-0.5.0-macos-x64.dmg`   | `Pebble-0.5.0-macos-x64.zip`   |

Windows: run the installer, or extract the entire ZIP before opening `Pebble.exe`.

macOS: open the DMG and drag Pebble to Applications. Choose the download matching About This Mac → Chip / Processor.

These preview builds are unsigned and the Mac builds are not notarized. If macOS blocks the app, see the [installation guide](https://github.com/chenwy777/pebble-todo#installation) and [Apple's guidance](https://support.apple.com/en-au/102445). Do not disable Gatekeeper globally. Checksums for all assets are in `SHA256SUMS.txt`.

## First use

- Hover over the orb to open the list. Drag the orb to move it; right-click to quit.
- No To-do items: the orb shows the P logo. Otherwise it shows the To-do count; Doing / Done are excluded.
- Add tasks under To-do, Doing or Done. Click the checkbox to advance a task, or its title to edit.
- English is the default. Use 中文 / EN to change the interface, or click the date to change its language independently.

## AI connections

Open Settings → AI connections, enable local access and copy the Codex or Claude configuration. Node.js 20+ is required only for AI connections; the desktop app works on its own. Keep Pebble running while using AI.

Tools: read local date / timezone, read categories, search tasks and add tasks. Additions update the list and orb immediately. Retries can reuse a request ID to avoid duplicates.

## Verification and limits

Windows desktop and MCP workflows have been exercised locally. CI builds Windows x64, macOS arm64 and macOS x64, and runs the unit tests on each platform. Mac packaging success does not establish manual validation of translucency, dragging, multiple displays or menu-bar behavior. Claude client UI acceptance is also still pending.

This version does not include reminder notifications, cloud sync, recurring tasks, actual time tracking, or editing / deleting existing tasks through MCP. Time fields describe a plan, not an alarm.
